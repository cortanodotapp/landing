
# Cortano Landing

Landing page for Cortano Project (https://cortano.app)


## Run Locally

Clone the project

```bash
  git clone git@github.com:CortanoAPP/landing.git
```

Go to the project directory

```bash
  cd landing
```

Install dependencies

```bash
  bun install
```

Start the server

```bash
  bun dev
```
